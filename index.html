GWS CLI privacy policy

Last updated: 22 November 2026

GWS CLI is a personal command-line tool that Kyle Naranjo uses to read and manage his own Google Workspace data (Gmail, Calendar, Drive, Sheets, and related services). It is not offered to other people.

What data it accesses

The tool accesses only the Google account that signs in to it, and only the scopes that account approves on the Google consent screen.

How data is stored

OAuth tokens are stored encrypted on the signed-in user's own computer. The tool has no server. It does not send Google user data to the developer or to any third party, and it does not sell, share, or use the data for advertising.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
